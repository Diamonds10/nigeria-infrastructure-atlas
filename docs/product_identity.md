# Infraxis Atlas product identity

## Master brand

**Infraxis Atlas** is the uniform pan-African master brand.

**Tagline:** *Mapping infrastructure. Measuring disruption.*

Country editions use the pattern `Infraxis Atlas — {Country}`. The first
edition is **Infraxis Atlas — Nigeria**. Future editions should preserve the
same country naming, core data taxonomy, provenance standards, contribution
controls, and API principles so users can compare infrastructure consistently
across African markets.

## Nigeria transition

Infraxis Atlas — Nigeria was published as **Nigeria Infrastructure Atlas**
through v0.11.1. The former name is retained in v0.12 metadata and citation
guidance for continuity, but it is no longer the public product name.

The existing repository, GitHub Pages, raw-download, and API URLs remain in
place during the transition. They are stable technical identifiers and must
not be interpreted as the current brand. Any future URL migration must provide
tested redirects before the legacy URLs are retired.

## Open atlas boundary

This repository contains the open country atlas:

- public-source infrastructure mapping;
- state profiles and downloadable reports;
- source provenance, quality notes, and reuse conditions;
- processed public datasets where redistribution permits;
- a versioned static API;
- reproducible processing and release checks; and
- open contribution and correction workflows.

The atlas is screening and planning evidence. It is not an official government
registry, live security feed, or substitute for field, legal, regulatory, or
commercial due diligence.

## Premium Infraxis boundary

Proprietary Infraxis products are separate from this open repository. They may
include forward-looking *What Might We Lose?* disruption scenarios,
retrospective *What Did We Actually Lose?* assessments, private client data,
financial assumptions, dependency and vulnerability models, portfolio
analytics, enterprise workspaces, and advisory services.

Nothing in this repository's CC0 dedication publishes, relicenses, or implies
access to proprietary Infraxis models, methods, parameters, software, or
client data. Third-party atlas data remains governed by its original source
terms as documented in `THIRD_PARTY_DATA.md` and `docs/data_sources.md`.

## Public description

> Infraxis Atlas — Nigeria is an open, continuously improving geospatial
> platform connecting infrastructure assets, energy access, communities,
> environmental conditions, and historical security exposure. It is the first
> country edition of Infraxis Atlas, a uniform pan-African infrastructure
> mapping platform.

## Naming examples

- Infraxis Atlas — Nigeria
- Infraxis Atlas — Ghana
- Infraxis Atlas — Kenya
- Infraxis Atlas — Africa

Do not use `official`, `national`, or `government` in a country-edition name
without formal written adoption by the relevant authority.
